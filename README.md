# QuantumSafe Chat

A Post-Quantum Secure Chat Application built using Python, Socket Programming, ML-KEM, ML-DSA, and AES.

## Objective

The goal of this project is to build a secure client-server chat application that is resistant to quantum computing attacks by integrating NIST standardized Post-Quantum Cryptography algorithms.

## Current Phase

Phase 1 – Networking Foundation

## Planned Features

- TCP Client-Server Communication
- Multi-threaded Chat
- Multiple Client Support
- AES Encryption
- ML-KEM Key Exchange
- ML-DSA Digital Signatures
- Graphical User Interface
